# Studio EEF — website

Statische één-pager (Nederlands, geen build-stap) voor schilderbedrijf
Studio EEF. **Live bekijken: <https://nielslagas.github.io/studio-eef-v2/>**
(de `gh-pages`-branch bevat alleen de site zelf).

## Mappen

| Map | Inhoud |
| --- | --- |
| `site/` | de actieve site (v2 "Verse verf" — flitsend redesign met beweging) |
| `site-v1/` | de eerste opzet (huisje/verfstalen-look), als archief |
| `_vision/` | inspectie- en testtooling + vision-rapporten |
| root | bronmateriaal (origineel logo, PDF, logo-alternatieven, generatiescripts) |

## Site openen

Open `site/index.html` in een browser — er is verder niets nodig
(geen build-stap, geen libraries). Zie `site/README.md` voor de details
(huisstijl, typografie, motion) en `site/ONTWERP-V2.md` voor de ontwerpbrief.

## Nog in te vullen door de eigenaar

Telefoonnummer, e-mail, KvK/BTW/adres en werkgebied — gemarkeerd met een
mosterthalo + stippellijn (zoek op `class="todo"` in `site/index.html`).
